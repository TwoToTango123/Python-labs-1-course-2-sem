# Лабораторная работа №1: Источники задач и контракты

## Цель
Реализовать подсистему приема задач через duck typing и контрактное программирование.

## Реализовано
- Единый контракт источника задач через `typing.Protocol` и `@runtime_checkable`.
- Runtime-проверка контракта через `isinstance(obj, TaskSourceProtocol)`.
- Минимальная модель задачи в формате `dict` с полями `id` и `payload`.
- Три независимых источника задач без общего базового класса:
	- источник из JSON-файла;
	- программный генератор;
	- API-заглушка.
- Единый модуль приема задач, работающий с любым источником, который удовлетворяет контракту.

## Требования
- Python 3.11+
- pytest
- pytest-cov

## Проверка покрытия
```bash
pytest --cov=src/task_platform --cov-report=term-missing --cov-fail-under=80
```

## Запуск через Docker

```bash
docker build -t lab1 .
docker run --rm lab1
```

При запуске выполняется:
1. `demo.py` - демонстрация трёх источников задач и единого модуля приёма.
2. `pytest` - все тесты с отчётом о покрытии.
